# Tideline

個人股票技術分析站。台股與美股，自訂觀察清單，每天收盤後產出每檔一頁的技術分析：
指標摘要、關鍵價位（賣出／止跌／加碼）與價格＋布林通道、KD 兩張圖。

指標與價位全部由程式計算，不經過語言模型。所有輸出僅供參考，不是投資建議。

## 做法

先本機 DEMO、先把爬蟲跑過真實資料，部署擺到最後再說。TDD——測試先寫、看它紅、才實作。

照 PLAN.md 的 §10，從 **Phase A 第 1 步**開始（純 Node 腳本，還不碰 Next.js／Supabase／雲端）。

計畫裡已經釘死、最容易寫錯的四件事：

- 布林通道用**母體**標準差（÷N），不是樣本標準差
- KD 的 RSV 用**盤中高低價**，不是收盤價的高低
- 台股用 **TWSE**，不要用 Yahoo（Yahoo 台股實測有幽靈 K 棒與 null 破洞）
- `daily_bars` 只留半年＋暖機可以清，**`daily_analysis` 一列都不能刪**——它是日後回顧的唯一素材
